02 / WHO DOES WHAT

Skill 规定方法，Agent 执行工作，人工作决定

AGENT 阅读、推导、编写、调用工具、核对证据人工 提出目标、确认预期、批准或退回执行工具 Gradle / JUnit / ADB / JaCoCo / Lint
输入与追溯

sdlc-input-analysis

由 Agent 按技能执行：阅读设计和源码，按六阶段整理输入，区分事实、假设、冲突与缺口。

交付：输入基线、需求—实现—测试追溯表、待决问题。

不把源码现状自动当需求；不负责声称测试已经通过。

内容版本与人工决定

content-review

Agent 操作：提交快照、打开审阅页、读取和核对审批记录。
人工操作：阅读、批准、退回或要求补充。

交付：reviewId、revision、SHA-256、决定、意见与时间。

不代写内容、不代替人工批准、不运行测试；批准只对应指定内容版本。

测试设计与工程验证

android-unit-test-workflow

由 Agent 按技能执行：划分 JVM / 设备测试，编写行为断言，运行回归，检查覆盖率及 Lint。

交付：测试源码、JUnit / JaCoCo / Lint 证据和统一报告。

不自行批准需求；不缩小覆盖分母或放宽断言来制造“通过”。

职责归属和实际执行者是两个维度。“归属 content-review”表示使用其审批机制；点击批准的是人工，提交和核验记录的是 Agent。Skill 之间的交接由 Agent 按用户指令组织，不代表自动互相触发。
本报告依据本次实际读取的三个 SKILL.md 与本地执行记录02 / 07
