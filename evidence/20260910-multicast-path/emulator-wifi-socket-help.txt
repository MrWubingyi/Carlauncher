
  by default, the emulator's virtio wifi device uses user mode networking which
  does address translation of all network traffic. Use -wifi-socket <option>
  to switch to Socket network mode where Virtio Wi-Fi will use a socket interface to
  connect to the host network directly. Android will attempt to configure the Socket
  network using DHCP for IPv4 and SLAAC for IPv6. To be able to access the
  network that the host is connected to the Socket interface should be backed
  with another network interface on the host.

  <option> depends on how the socket is configured. It could be one of fd=, listen=,
  or connect=. See https://wiki.qemu.org/Documentation/Networking#Socket
