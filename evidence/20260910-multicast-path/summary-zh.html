为什么 TCP 可用，而原组播不通

原网络走模拟器用户态 NAT：10.0.2.16 → Windows 192.168.31.85 → Ubuntu 192.168.31.248。单播 TCP/UDP 回复沿现有映射返回；这不会自动把虚拟网内组播接到外部局域网。

独立套接字实测 Windows ↔ Ubuntu 组播双向可达，无系统路由修改。Windows 收到 119 个 Ubuntu 标记，Ubuntu 收到 115 个 Windows 标记（包含链路重复）。Ubuntu 默认组播出口为 VPN tun0；指定 ens33 能解决本机出口，却不能独自打通模拟器边界。
